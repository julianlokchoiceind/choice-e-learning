# Codebase Pre-Check Rules

Always thoroughly search codebase using grep_search and file_search before creating new files. Check existing API endpoints, hooks, services, and UI components. Never arbitrarily change current system structure. Prioritize reusing existing code.

## Required Steps:
1. Search thoroughly in codebase using grep_search and file_search
2. Check existing API endpoints before creating new ones
3. Review already implemented hooks and services
4. Utilize existing UI components
5. Follow current directory structure and naming conventions

## Key Points:
- Prevent duplicate files/directories/features
- Maintain system stability during fixes or implementations
- Never change existing system structure without necessity
- Always prioritize reusing existing components, hooks, and services
