# System Consistency Requirements

Use existing Loading State Components. Use existing React Query setup. Never create custom code for individual parts - always base on system's existing consistency patterns.

## Requirements:
1. **Loading States**: Always use existing LoadingState Component with proper variants
2. **Data Fetching**: Use existing React Query setup and patterns
3. **No Custom Solutions**: Never create custom code for individual parts
4. **System Patterns**: Always base implementation on existing system consistency patterns

## Available Components:
- LoadingState component with multiple variants (page, section, table, button)
- React Query infrastructure with optimized configuration
- Error handling with toast notifications
- Established providers and context patterns
