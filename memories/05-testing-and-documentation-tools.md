# Testing and Documentation Tools

Use Playwright for testing and checking functionality. Use MCP Context7 to find proper documentation for features.

## Testing Tools:
- **Playwright**: Use for end-to-end testing and functionality verification
- **Browser Testing**: Check UI components and user interactions
- **Regression Testing**: Ensure changes don't break existing functionality

## Documentation Tools:
- **MCP Context7**: Use to find proper documentation for specific features
- **Feature Research**: Look up best practices and implementation guides
- **Technology Documentation**: Access up-to-date library and framework docs

## Workflow:
1. When fixing bugs or implementing features, use Playwright to check functionality
2. Use MCP Context7 to find relevant documentation and best practices
3. Test thoroughly before considering implementation complete
4. Document any new patterns or significant changes
