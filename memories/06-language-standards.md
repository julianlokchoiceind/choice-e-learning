# Language Standards

All code content must use English except comments which can use Vietnamese. Variable names, functions, directories, and files must use English for consistency.

## Language Rules:
1. **Code Content**: All code must be written in English
2. **Comments**: Can use Vietnamese for better understanding
3. **Variable Names**: Must use English
4. **Function Names**: Must use English
5. **Directory Names**: Must use English
6. **File Names**: Must use English

## Benefits:
- **Consistency**: Ensures codebase consistency across the project
- **Professionalism**: Maintains professional standards
- **Collaboration**: Easier for international developers to understand
- **Maintainability**: Reduces confusion and improves code readability

## Examples:
✅ **Correct**:
```javascript
const userProfile = {...}; // Hồ sơ người dùng
function getUserData() {...}
```

❌ **Incorrect**:
```javascript
const hoSoNguoiDung = {...};
function layDuLieuNguoiDung() {...}
```
