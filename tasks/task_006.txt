# Task ID: 6
# Title: Create useToast Hook for Toast Notifications
# Status: pending
# Dependencies: 5
# Priority: high
# Description: Create a new useToast hook in src/client/hooks/common/useToast.ts that provides a convenient interface for using toast notifications throughout the application as specified in section 3.5 of the PRD.
# Details:
The developer should:

1. Create a new file at src/client/hooks/common/useToast.ts
2. Implement a custom React hook that leverages the ToastProvider component created in Task #5
3. The hook should expose the following functionality:
   - `success(message: string, options?: ToastOptions)`: Display a success toast
   - `error(message: string, options?: ToastOptions)`: Display an error toast
   - `warning(message: string, options?: ToastOptions)`: Display a warning toast
   - `info(message: string, options?: ToastOptions)`: Display an info toast
   - `loading(message: string, options?: ToastOptions)`: Display a loading toast
   - `dismiss(toastId?: string)`: Dismiss a specific toast or all toasts
   - `custom(message: string, options?: ToastOptions)`: Display a custom toast

4. Each method should properly integrate with react-hot-toast's API
5. The hook should handle proper type definitions for all parameters and return values
6. Include appropriate JSDoc comments for each function
7. Ensure the hook can be used within any component that is a child of the ToastProvider
8. Handle edge cases such as:
   - Components trying to use the hook outside of ToastProvider context
   - Invalid parameters passed to toast functions
   - Proper cleanup when components unmount

The implementation should follow the project's coding standards and be consistent with the existing codebase.

# Test Strategy:
To verify the successful implementation of the useToast hook:

1. **Unit Testing**:

2. **Integration Testing**:

4. **Documentation Verification**:
   - Ensure JSDoc comments are complete and accurate
   - Verify TypeScript types are correctly defined
   - Check that the implementation matches the requirements in PRD section 3.5

5. **Code Review**:
   - Have another developer review the implementation
   - Verify the hook follows project coding standards
   - Ensure the hook properly integrates with the ToastProvider from Task #5
