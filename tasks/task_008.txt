# Title: Create useQueryUtils Helper for React Query Error Handling
# Status: done
# Dependencies: 4, 6

# Description: Create a new utility hook in src/client/hooks/common/useQueryUtils.ts that provides helper functions for React Query error handling, including onError function and showErrorToast functionality as specified in PRD section 3.7.
# Details:
This task involves creating a new TypeScript file at src/client/hooks/common/useQueryUtils.ts that will provide utility functions for React Query error handling.

The implementation should:
1. Import the useToast hook from src/client/hooks/common/useToast.ts (created in Task #6)
2. Create and export a useQueryUtils hook that returns:
   - An onError function that handles React Query errors consistently
   - A showErrorToast function that displays error messages using the toast notification system
3. The onError function should:
   - Accept an error parameter (from React Query)
   - Log the error to the console for debugging
   - Call the showErrorToast function with an appropriate error message
4. The showErrorToast function should:
   - Use the useToast hook to display error notifications
   - Handle different error types (network errors, API errors, etc.)
   - Extract and display meaningful error messages from error objects
   - Provide fallback generic error messages when specific error details aren't available
5. Ensure the hook is properly typed with TypeScript
6. Add appropriate JSDoc comments to document the hook's functionality and parameters

The implementation should follow the guidelines in PRD section 3.7 and integrate with the existing React Query setup from Task #4 (ReactQueryProvider).
