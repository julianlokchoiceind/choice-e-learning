# Description: Implement a custom React Query hook in src/client/hooks/courses/useCoursesQuery.ts that provides CRUD operations for course data according to PRD sections 3.7 and 4.1.
# Details:
The useCoursesQuery hook should be implemented in a new file at src/client/hooks/courses/useCoursesQuery.ts. This hook will serve as the primary interface for all course-related data operations.

Implementation requirements:
1. Import necessary dependencies:
   - React Query hooks (useQuery, useMutation, useQueryClient)
   - API service functions for course operations
   - useQueryUtils hook for error handling
   - useToast hook for success notifications

2. Implement the following query functions:
   - useGetCourses(): Fetches a list of all courses
   - useGetCourseById(id): Fetches a specific course by ID
   - useCreateCourse(): Creates a new course
   - useUpdateCourse(): Updates an existing course
   - useDeleteCourse(): Deletes a course

3. Each function should:
   - Properly handle loading, error, and success states
   - Utilize the useQueryUtils hook for standardized error handling
   - Show appropriate toast notifications on success/failure
   - Implement proper cache invalidation and updates
   - Return relevant data and state information

4. Follow the patterns and guidelines specified in PRD sections 3.7 and 4.1, ensuring consistency with the application's data management approach.

5. Implement proper TypeScript typing for all parameters, return values, and internal variables.

6. Add comprehensive JSDoc comments for the hook and all its functions.

This hook depends on the previously completed ReactQueryProvider, useToast, and useQueryUtils implementations.
