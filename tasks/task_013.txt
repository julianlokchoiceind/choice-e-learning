# Status: done

# Description: Create a new hook in src/client/hooks/faq/useFAQsQuery.ts that provides CRUD operations for FAQ data according to PRD section 4.3.
# Details:
This task involves creating a new custom React Query hook for managing FAQ data operations:

1. Create a new file at `src/client/hooks/faq/useFAQsQuery.ts`
2. Implement the hook to provide the following CRUD operations:
   - `getFAQs()`: Fetch all FAQs
   - `getFAQ(id)`: Fetch a specific FAQ by ID
   - `createFAQ(data)`: Create a new FAQ
   - `updateFAQ(id, data)`: Update an existing FAQ
   - `deleteFAQ(id)`: Delete an FAQ

3. Utilize the ReactQueryProvider context from Task #4 for query caching and state management
4. Implement proper error handling using the useQueryUtils hook from Task #8
5. Display appropriate toast notifications using the useToast hook from Task #6
6. Follow the API specifications defined in PRD section 4.3
7. Ensure proper TypeScript typing for all parameters and return values
8. Implement query invalidation to refresh data after mutations
9. Add appropriate comments and documentation for the hook functions

The hook should be designed to be easily imported and used by any component that needs to interact with FAQ data.
