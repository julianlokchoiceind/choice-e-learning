# Details:
This task involves creating a custom React Query hook that will handle all CRUD operations for lesson data:

1. Create a new file at `src/client/hooks/learn/useLessonsQuery.ts`
2. Implement the following functionality in the hook:
   - `useGetLessons()`: Query to fetch all lessons
   - `useGetLesson(id)`: Query to fetch a specific lesson by ID
   - `useCreateLesson()`: Mutation to create a new lesson
   - `useUpdateLesson()`: Mutation to update an existing lesson
   - `useDeleteLesson()`: Mutation to delete a lesson

The hook should:
- Utilize the ReactQueryProvider context for caching and state management
- Implement proper error handling using the useQueryUtils hook
- Display appropriate toast notifications on success/error using useToast
- Include TypeScript interfaces for lesson data structure
- Follow the API endpoints and data structures specified in PRD section 4.4
- Implement query invalidation to ensure data consistency after mutations
- Include proper loading states and error handling
- Add JSDoc comments for all exported functions

The implementation should follow React Query best practices, including:
- Using appropriate query keys for caching
- Implementing optimistic updates where applicable
- Handling pagination if required by the PRD
- Providing retry logic for failed requests
