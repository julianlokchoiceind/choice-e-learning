# Task ID: 21
# Title: Task #21: Update Components to Use New React Query Hooks
# Status: done
# Dependencies: 11, 12, 13, 14, 15, 16, 17, 18
# Priority: high
# Description: Refactor multiple components across the admin and course sections to replace existing data fetching methods with the newly created React Query hooks.
# Details:
This task involves updating various components to use the React Query hooks that were created in previous tasks. The components are divided into two main categories: Admin Components and Course Components.

For Admin Components:
1. Update `src/client/components/admin/students/StudentList.tsx`, `src/client/components/admin/students/StudentForm.tsx`, and `src/client/components/admin/students/StudentDetail.tsx` to use the `useStudentsQuery` hook for fetching and manipulating student data.
2. Update `src/client/components/admin/topics/TopicList.tsx` and `src/client/components/admin/topics/TopicForm.tsx` to use the `useTopicsQuery` hook for topic-related operations.
3. Update `src/client/components/admin/lessons/LessonList.tsx` and `src/client/components/admin/lessons/LessonForm.tsx` to use the `useLessonsQuery` hook for lesson data management.
4. Update `src/client/components/admin/CourseManager.tsx` to use the `useCoursesQuery` hook for course management operations.

For Course Components:
1. Update `src/client/components/courses/CourseCard.tsx`, `src/client/components/courses/CourseDetail.tsx`, and `src/client/components/courses/CoursesSection.tsx` to use the `useCoursesQuery` hook.
2. Additionally, update `src/client/components/courses/CoursesSection.tsx` to also use the `useTopicsQuery` hook for topic filtering functionality.
3. Update `src/client/components/courses/EnrollButton.tsx` to use both `useCoursesQuery` and `useAuthQuery` hooks for enrollment functionality.

Implementation Guidelines:
- Remove any existing data fetching logic (like useState, useEffect combinations or Redux-based approaches).
- Replace with appropriate React Query hook calls.
- Update component logic to handle loading, error, and data states provided by React Query.
- Ensure proper TypeScript typing throughout the refactoring.
- Maintain existing component functionality while improving performance and code organization.
- Use React Query's built-in caching and invalidation features where appropriate.
- Update any related tests to account for the new data fetching approach.

This task depends on the successful completion of Tasks #11-18, which created the React Query hooks that will be used in this refactoring.
