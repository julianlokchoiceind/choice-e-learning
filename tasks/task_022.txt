3. Dashboard Components:
   - Update `src/client/components/dashboard/UserLoginStreak.tsx` to use `useUserQuery` for user streak data

4. Other Components:
   - Update `src/client/components/topics/TopicsFilter.tsx` to use `useTopicsQuery` for topic filtering
   - Update `src/client/components/faq/FAQSection.tsx` to use `useFAQsQuery` for FAQ data
   - Update `src/client/components/ui/file/FileUpload.tsx` to use appropriate React Query hooks for file operations
   - Update `src/client/components/auth/ProtectedRoute.tsx` to use `useAuthQuery` for authentication checks

5. Admin Pages:
   - Update all pages in `src/app/admin/` to use the corresponding React Query hooks based on their functionality

6. Public Pages:
   - Update `src/app/courses/page.tsx` to use `useCoursesQuery` and `useTopicsQuery`
   - Update `src/app/courses/[courseId]/page.tsx` to use `useCoursesQuery` and `useLessonsQuery`
   - Update `src/app/(dashboard)/dashboard/page.tsx` to use `useCoursesQuery` and `useUserQuery`
   - Update `src/app/(dashboard)/my-courses/page.tsx` to use `useCoursesQuery`
   - Update `src/app/(auth)/login/page.tsx` and `signup/page.tsx` to use `useAuthQuery`
   - Update `src/app/(marketing)/faq/page.tsx` to use `useFAQsQuery`
   - Update `src/app/(marketing)/reviews/page.tsx` to use appropriate React Query hooks
   - Update `src/app/(marketing)/roadmap/page.tsx` to use appropriate React Query hooks

Implementation Notes:
- Replace direct API calls with the appropriate React Query hooks
- Ensure proper error handling and loading states are implemented
- Maintain component functionality while transitioning to React Query
- Leverage React Query's caching capabilities for improved performance
- Use the appropriate query parameters and mutation functions from the hooks
- Ensure proper TypeScript typing throughout the implementation
- Follow the project's coding standards and patterns
